# 持仓管理与AI交易功能使用说明

## 功能概述

本次更新为AI量化交易系统添加了以下新功能:

1. **持仓管理模块** - 记录和管理您的真实持仓信息
2. **回测集成持仓** - 在回测时对比真实持仓表现
3. **实时监控AI建议** - 根据持仓情况生成个性化交易建议
4. **AI智能决策** - 结合持仓状态和AI预测给出买入/卖出建议

---

## 一、持仓管理功能

### 1.1 持仓管理标签页

在主界面左侧新增了"💼 持仓管理"标签页,包含以下功能:

#### 资金信息
- 显示当前可用资金
- 显示总资产(现金+持仓市值)
- 显示总盈亏(金额和百分比)

#### 持仓明细表格
- 股票代码和名称
- 持仓数量(手)
- 成本价和当前价
- 市值和盈亏(金额和百分比)
- 盈亏用颜色标识(绿色为正,红色为负)

#### 持仓操作
- **买入**: 输入股票代码、数量、价格,点击买入
- **卖出**: 输入股票代码、数量、价格,点击卖出
- **刷新持仓**: 更新持仓列表显示
- **交易记录**: 查看所有买入卖出历史
- **清空持仓**: 清空所有持仓数据(需确认)

### 1.2 数据存储

持仓数据自动保存在两个文件中:
- `portfolio.pkl` - 二进制格式,程序读取使用
- `portfolio.json` - JSON格式,便于查看和备份

## 二、回测功能增强

### 2.1 回测时显示持仓对比

当执行AI回测时,系统会:

1. 显示当前持仓信息(如果有)
2. 在回测结果中对比:
   - 回测策略收益率
   - 实际持仓收益率
   - 给出策略评价

### 2.2 AI交易建议生成

根据回测结果和当前持仓,系统会给出AI交易建议:

- **策略优秀(收益率>10%)**:
  - 如持有该股票,显示买入/卖出/持有建议
  - 建议可考虑按策略操作

- **策略一般(收益率0-10%)**:
  - 建议继续观察,谨慎操作

- **策略不佳(收益率<0%)**:
  - 暂不建议实际交易
  - 建议优化参数或更换策略

## 三、实时监控功能增强

### 3.1 监控面板显示持仓

实时监控面板新增:
- 顶部显示当前持仓总览
  - 总资产
  - 总盈亏(金额和百分比)

### 3.2 AI交易建议列

在监控表格中新增"AI交易建议"列,根据以下因素综合判断:

- **AI预测信号** (看涨/看跌/中性)
- **当前持仓状态** (有持仓/无持仓)
- **持仓盈亏情况** (盈利/亏损及百分比)

### 3.3 交易建议逻辑

系统会根据不同情况给出建议:

#### 无持仓时:
- AI看涨 → **建议买入建仓**
- AI看跌/中性 → **建议观望**

#### 有持仓时:

| AI预测 | 持仓盈亏 | 建议 |
|--------|----------|------|
| 看涨 | 亏损>5% | 建议加仓摊低成本 |
| 看涨 | 盈利<5% | 建议继续持有 |
| 看涨 | 盈利>5% | 可考虑分批止盈 |
| 看跌 | 盈利>5% | 建议及时止盈 |
| 看跌 | 小幅盈利 | 建议减仓或清仓 |
| 看跌 | 亏损 | 建议止损 |
| 中性 | 盈利>10% | 建议止盈 |
| 中性 | 亏损>10% | 建议止损 |
| 中性 | 其他 | 建议继续持有 |

## 四、使用示例

### 示例1: 新手投资者

1. 打开持仓管理标签页
2. 买入股票: `000001`, 数量: `100`手, 价格: `10.50`元
3. 前往实时监控标签页,输入股票代码: `000001`
4. 开始监控,系统会根据持仓给出交易建议

### 示例2: 有经验投资者

1. 先进行回测,测试策略表现
2. 查看回测结果和持仓对比
3. 根据AI建议决定是否实际操作
4. 在实时监控中持续跟踪,结合持仓和AI信号调整

### 示例3: 程序化交易

```python
from 持仓管理 import PortfolioManager

# 创建持仓管理器
pm = PortfolioManager('my_portfolio.pkl')

# 添加持仓
pm.add_position('000001', '平安银行', 100, 10.50)

# 获取AI交易建议
signal, reason = pm.get_ai_trading_signal(
    stock_code='000001',
    ai_prediction=1,  # AI看涨
    current_price=11.20
)

if signal == 'BUY':
    print(f"建议买入: {reason}")
elif signal == 'SELL':
    print(f"建议卖出: {reason}")
else:
    print(f"建议持有: {reason}")
```

## 五、注意事项

### 5.1 风险提示

1. **AI预测仅供参考**: AI预测基于历史数据,不能保证未来表现
2. **交易需自主决策**: 系统建议仅供参考,请结合实际情况自主决策
3. **注意仓位管理**: 建议单只股票仓位不超过总资金的20%
4. **及时止损**: 亏损超过10%时应考虑止损

### 5.2 数据备份

定期备份持仓数据文件:
- `portfolio.pkl`
- `portfolio.json`

### 5.3 数据准确性

- 确保录入的买入/卖出信息准确
- 及时更新持仓的当前价格
- 定期核对持仓与实际账户一致

## 七、常见问题

### Q1: 如何清空持仓数据?

A: 在持仓管理标签页点击"清空持仓"按钮,确认后即可清空。

### Q2: 持仓数据保存在哪里?

A: 数据保存在程序目录下的 `portfolio.pkl` 和 `portfolio.json` 文件中。

### Q3: AI交易建议的准确率如何?

A: AI建议基于机器学习模型和历史数据,准确率取决于市场环境和模型质量。建议作为参考,不作为唯一依据。

### Q4: 回测和实际持仓为什么有差异?

A: 回测使用历史数据,实际持仓使用当前价格,两者可能因价格波动、手续费、分红等因素产生差异。

### Q5: 如何提高AI建议的准确性?

A:
- 使用更长时间的训练数据
- 优化AI模型参数
- 结合多种技术指标
- 考虑基本面因素
