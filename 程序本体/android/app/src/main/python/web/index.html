📖 实盘下单设置步骤

  1. 打开并登录你的券商交易客户端（如"同花顺"，登录资金账号）。
  2. 找到客户端的下单程序（通常是 xiadan.exe），点「自动检测」或手动填写路径。
  3. 选择你的券商类型（默认 universal 通用同花顺）。
  4. 资金账号/密码可留空：客户端已登录时只需附加连接。
  5. 点「🔌 检测连接」确认下单程序可用，再「▶️ 启动引擎」。

⚠️ 真实下单会动真金白银，建议先用模拟交易熟悉策略。

❓ 软件教学

新手上手指南

🚀 推荐上手顺序

  1. 🤖 智能推荐 - 先看推荐榜单了解市场机会。
  2. 🔎 智能查询 - 输入代码查 K 线、走势、AI 诊断。
  3. 📥 数据抓取 - 下载历史日 K 线到「金融数据」目录。
  4. 📈 走势分析 - 对已下载数据批量生成分析报告。
  5. 🧪 AI 回测 - 用历史数据测试策略收益率。
  6. 👀 盘中监控 - 交易时段让 AI 盯盘给信号。
  7. 🤖 全自动交易 - 先用「模拟交易」，熟悉后再连券商。

📌 常用名词

  • RSI 强弱指标，>70 超买、<30 超卖。
  • MACD 趋势指标，金叉看多、死叉看空。
  • KDJ 随机指标，低位金叉是买点信号。
  • K 线 每根记录开高低收与成交量。
  • 收益率 期末资产相对期初的百分比变化。
  • 买入持有 同区间不做任何操作只买不卖的基准。
