# 基金交易功能说明

## 功能概述

已在AI量化交易系统中添加基金交易功能,支持基金的查询、买入、卖出、持仓管理等完整功能。

## 新增内容

### 1. GUI界面

在主界面添加了"💵 基金交易"标签页,包含以下功能:

- **基金查询**: 输入基金代码查询基金基本信息和最新净值
- **基金持仓**: 显示当前持有的所有基金,包括代码、名称、类型、份额、成本净值、最新净值、市值、盈亏等
- **买入基金**: 按金额买入基金份额
- **卖出基金**: 按份额卖出基金
- **刷新净值**: 一键更新所有持仓基金的最新净值
- **交易记录**: 查看所有基金交易历史
- **清空持仓**: 清空所有基金持仓

### 2. 核心类

#### FundPosition (基金持仓类)

管理单只基金的持仓信息,包括:
- 基金代码、名称、类型
- 持仓份额
- 平均成本净值
- 最新净值
- 买入日期
- 盈亏计算

#### FundManager (基金管理器类)

管理整个基金投资组合,包括:
- 添加持仓(买入)
- 减少持仓(卖出)
- 更新所有基金净值
- 计算总资产和盈亏
- 交易历史记录
- 数据持久化(pickle + JSON)

### 3. 数据获取

使用akshare库获取基金数据:
- ETF基金: `ak.fund_etf_spot_em()` 获取实时净值
- 开放式基金: `ak.fund_em_open_fund_info()` 获取历史净值
- 基金搜索: `ak.fund_em_open_fund_search()` 搜索基金

如果未安装akshare,系统会使用模拟数据进行演示。

## 使用方法

### 1. 查询基金

1. 在"基金交易"标签页的"基金查询"区域输入基金代码(如: 159915)
2. 点击"🔍 查询基金"按钮
3. 系统会显示基金名称、最新净值、净值日期等信息

### 2. 买入基金

1. 在"基金交易"区域输入基金代码(如: 159915)
2. 输入购买金额(如: 1000元)
3. 点击"💰 买入"按钮
4. 系统会根据最新净值自动计算份额并完成买入

### 3. 卖出基金

1. 在"基金交易"区域输入基金代码(如: 159915)
2. 输入卖出份额(如: 500份)
3. 点击"💸 卖出"按钮
4. 系统会根据最新净值计算金额并完成卖出

### 4. 更新净值

1. 点击"🔄 刷新净值"按钮
2. 系统会自动更新所有持仓基金的最新净值
3. 盈亏情况会自动重新计算

### 5. 查看交易记录

1. 点击"📜 交易记录"按钮
2. 弹出窗口显示所有基金交易历史
3. 包括日期、操作类型、基金信息、净值、份额、金额、盈亏等

## 数据存储

基金持仓数据保存在以下文件中:
- `fund_portfolio.pkl` - 二进制格式(程序使用)
- `fund_portfolio.json` - JSON格式(可手动查看)

文件位置: 与程序在同一目录下

## 基金类型

- 混合型基金
- 股票型基金
- 债券型基金
- 货币基金

- 000001 - 华夏成长混合

## 注意事项

1. **实时性**: 基金净值通常在每日收盘后更新,实时性不如股票
2. **申购赎回**: 普通基金的申购赎回有T+1确认期
3. **费用**: 实际交易时需要考虑申购费、赎回费、管理费等
4. **最低金额**: 部分基金有最低申购金额限制(通常是1元或10元)
