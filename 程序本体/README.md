## ✨ 功能特性

### 🎯 核心功能

| 功能模块 | 说明 | 状态 |
|---------|------|------|
| 📥 **数据爬取** | 支持批量下载股票历史数据 | ✅ |
| 🤖 **AI回测** | 8种机器学习模型可选 | ✅ |
| 📡 **实时监控** | 多股票实时监控与AI预测 | ✅ |
| 📊 **数据分析** | 自动生成HTML可视化报告 | ✅ |
| 🎨 **图形界面** | 现代化GUI，操作简单 | ✅ |
| 🧵 **多线程** | 异步处理，界面不卡顿 | ✅ |

### 🧠 AI模型支持

- ✅ 随机森林 (Random Forest) - 速度快，精度高
- ✅ 梯度提升树 (Gradient Boosting) - 精度很高
- ✅ 神经网络 (Neural Network) - 学习能力强
- ✅ 逻辑回归 (Logistic Regression) - 速度最快
- ✅ 支持向量机 (SVM) - 精度高
- ✅ AdaBoost - 自适应提升
- ✅ 决策树 (Decision Tree) - 简单直观
- ✅ 朴素贝叶斯 (Naive Bayes) - 速度快

### 📈 技术指标

支持以下技术指标的计算和分析：

- **均线系统**: MA5, MA10, MA20, MA60
- **趋势指标**: MACD, DIF, DEA
- **摆动指标**: RSI (相对强弱指标)
- **通道指标**: 布林带 (Bollinger Bands)
- **成交量**: VOL, VOL_MA5, VOL_MA10

## 🚀 快速开始

### 📋 前置要求

- Python 3.8 或更高版本
- Windows 10/11, macOS 或 Linux
- 至少 4GB 内存
- 1GB 可用磁盘空间

### 📦 安装步骤

#### 方法一：使用批处理脚本（Windows，推荐）

1. **安装依赖**
   ```bash
   双击运行: 安装依赖.bat
   ```

2. **启动程序**
   ```bash
   双击运行: 启动GUI.bat
   ```

#### 方法二：手动安装

1. **克隆或下载项目**
   ```bash
   cd 量化交易/程序本体
   ```

2. **安装Python依赖**
   ```bash
   pip install -r requirements.txt
   ```
   
   或者分步安装：
   ```bash
   pip install pandas numpy scipy scikit-learn
   pip install akshare yfinance tushare
   pip install customtkinter requests openpyxl
   ```

3. **启动GUI程序**
   ```bash
   python AI量化交易系统GUI.py
   ```

### ⚡ 一分钟上手

1. 启动程序后，选择"📥 数据爬取"标签页
2. 输入股票代码（如：`000001`）
3. 点击"🚀 开始爬取"
4. 等待数据下载完成
5. 切换到"🤖 AI回测"，开始策略测试！

## 📖 使用说明

### 1️⃣ 数据爬取

```
功能：批量下载股票历史数据

步骤：
1. 输入股票代码（支持批量）
   单个: 000001
   批量: 000001,000002,600000
2. 设置时间范围
3. 点击"开始爬取"

数据保存在: 金融数据/ 文件夹
```

### 2️⃣ AI回测

```
功能：测试AI交易策略表现

步骤：
1. 输入股票代码
2. 选择AI模型
3. 点击"开始回测"

输出指标：
- 收益率
- 胜率  
- 交易次数
- 超额收益
```

### 3️⃣ 实时监控

```
功能：实时监控多只股票并给出交易建议

步骤：
1. 输入股票代码（支持批量）
2. 选择AI模型
3. 设置刷新间隔
4. 点击"开始监控"

显示信息：
- 最新价格
- 涨跌幅
- RSI/MACD指标
- AI预测信号
- 操作建议（买入/卖出/观望）
```

### 4️⃣ 数据分析

```
功能：生成数据分析HTML报告

步骤：
1. 确认数据目录
2. 可选：启用AI分析
3. 点击"开始分析"

报告包含：
- 数据基本信息
- 统计分析
- 数据洞察
- 可视化图表
```

## 🔧 高级配置

### 自定义数据路径

编辑 `爬取金融数据.py`:
```python
DATA_DIR = r"你的自定义路径"
```

### 调整AI模型参数

编辑 `多模型AI量化交易.py`:
```python
AI_MODELS = {
    '1': {
        'params': {
            'n_estimators': 100,  # 调整这里
            'max_depth': 10,
            'random_state': 42
        }
    }
}
```

### 配置AI分析

在数据分析功能中可配置：
- Ollama（本地AI模型）
- OpenAI兼容API
- 自定义API地址

## ❓ 常见问题

<details>
<summary><b>Q: 程序启动失败怎么办？</b></summary>

检查以下几点：
1. Python版本是否 >= 3.8
2. 依赖是否已安装（运行`安装依赖.bat`）
3. 查看错误信息，可能缺少某个库
</details>

<details>
<summary><b>Q: 数据爬取失败？</b></summary>

可能原因：
1. 网络连接问题
2. 股票代码错误
3. 数据源服务器繁忙（稍后重试）
4. 尝试更新AKShare: `pip install --upgrade akshare`
</details>

<details>
<summary><b>Q: AI预测准确吗？</b></summary>

注意事项：
1. AI预测是概率性的，不是100%准确
2. 首次使用需要训练模型
3. 历史数据不足会影响准确性
4. 建议结合多个指标综合判断
5. **投资有风险，仅供学习参考！**
</details>

<details>
<summary><b>Q: 可以监控多少只股票？</b></summary>

- 理论上无限制
- 建议不超过10只（避免请求频繁）
- 太多会增加刷新时间
</details>
