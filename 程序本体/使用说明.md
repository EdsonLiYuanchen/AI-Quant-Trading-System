## 🎯 系统简介

**AI量化交易系统** 是一个集成了数据爬取、AI智能分析、策略回测和实时监控的综合性量化交易平台。

### 核心功能
- ✅ **批量数据爬取** - 支持同时下载多只股票的历史数据
- ✅ **8种AI模型** - 随机森林、梯度提升树、神经网络等
- ✅ **智能策略回测** - AI增强的交易策略测试
- ✅ **实时行情监控** - 多股票实时监控与交易信号
- ✅ **数据分析报告** - 自动生成HTML可视化报告

### 技术优势
- 🚀 多线程异步处理，界面不卡顿
- 🎨 现代化图形界面，操作简单
- 🧠 机器学习驱动，智能决策
- 📊 详细日志输出，过程透明

### 2️⃣ AI回测

**功能说明：**
使用历史数据测试AI交易策略的表现

**操作步骤：**
1. 切换到"🤖 AI回测"标签页
2. 输入要回测的股票代码: `000001`
3. 选择AI模型（8种可选）：
   - **随机森林** - 速度快，精度高（推荐新手）
   - **梯度提升树** - 精度很高，速度中等
   - **神经网络** - 学习能力强，适合复杂模式
   - **逻辑回归** - 速度最快，精度中等
   - **支持向量机** - 精度高，速度较慢
   - **AdaBoost** - 自适应提升
   - **决策树** - 简单直观
   - **朴素贝叶斯** - 速度快
4. 点击"▶️ 开始回测"
5. 查看回测结果：
   - 交易次数
   - 胜率
   - 收益率
   - 超额收益

**多模型对比：**
1. 点击"📊 多模型对比"
2. 勾选要对比的模型
3. 点击"开始对比"
4. 查看各模型表现排行

**回测指标解释：**
- **收益率**: 策略产生的总收益百分比
- **胜率**: 盈利交易占总交易的比例
- **买入持有收益率**: 如果一直持有的收益
- **超额收益**: 策略收益 - 买入持有收益

### 3️⃣ 实时监控

**功能说明：**
实时监控多只股票并提供AI交易建议

**操作步骤：**
1. 切换到"📡 实时监控"标签页
2. 输入股票代码（支持批量监控）

## ❓ 常见问题

### Q1: 程序启动失败？
**A**: 检查以下几点：
1. Python是否已安装（建议3.8+）
2. 依赖是否已安装（运行`安装依赖.bat`）
3. 查看错误信息，可能缺少某个库

### Q2: 数据爬取失败？
**A**: 可能原因：
1. 网络连接问题
2. 股票代码错误（检查是否包含市场前缀）
3. 数据源服务器繁忙（稍后重试）
4. AKShare库版本问题（尝试更新：`pip install --upgrade akshare`）

### Q3: AI模型训练很慢？
**A**: 这是正常现象，取决于：
1. 数据量大小（数据越多越慢）
2. 模型类型（神经网络、SVM较慢）
3. 电脑性能
- 建议首次使用选择"随机森林"（速度快）

### Q4: 实时监控不准确？
**A**: 注意事项：
1. 首次使用需要训练模型
2. 历史数据不足会影响准确性
3. AI预测是概率性的，不是100%准确
4. 建议结合多个指标综合判断

### Q5: 如何清空下载的数据？
**A**: 两种方法：
1. 菜单栏 -> 文件 -> 清空数据文件夹
2. 运行独立的`清空金融数据.py`脚本

### Q6: 可以同时监控多少只股票？
**A**: 
- 理论上无限制
- 建议不超过10只（避免请求过于频繁）
- 太多会增加刷新时间

### Q7: 如何导出回测结果？
**A**: 
- 回测结果会显示在日志区域
- 可以复制日志内容保存
- 模型训练后会自动保存为`.pkl`文件

## ⚙️ 高级配置

### 自定义数据存储路径

编辑 `爬取金融数据.py`，修改：
```python
DATA_DIR = r"你的自定义路径"
```

### 配置AI分析模型

编辑 `分析数据.py`，在主函数中配置：
```python
ai_config = {
    'model_type': 'ollama',  # 或 'openai_compatible'
    'model_name': 'llama2',  # 你的模型名称
    'api_url': 'http://localhost:11434/api/generate'
}
```

### 调整监控刷新间隔

在监控标签页直接修改，或编辑代码：
```python
refresh_interval = 60  # 秒
```

### 修改AI模型参数

编辑 `多模型AI量化交易.py`，修改 `AI_MODELS` 字典中的参数：
```python
AI_MODELS = {
    '1': {
        'params': {
            'n_estimators': 100,  # 树的数量
            'max_depth': 10,      # 树的深度
            'random_state': 42
        }
    }
}
```

### 自定义交易策略

编辑 `AITradingStrategy` 类中的：
- `buy_signal()` - 买入条件
- `sell_signal()` - 卖出条件
- `best_params` - 技术指标参数
