# 🤖 AI量化交易系统 - 智能数据管理功能说明

## 📋 功能概述

新增的**智能数据管理功能**可以帮助您：
- 🔍 **实时监控**数据存储占用情况
- 📊 **可视化展示**存储使用情况
- 🧹 **智能清理**超过设定上限的数据
- ⚙️ **灵活配置**清理策略和选项

## 💾 功能特性

### 1. 实时数据监控
- **进度条可视化**: 实时显示数据占用百分比
- **颜色警示**: 不同颜色表示不同状态（绿/橙/红）
- **详细统计**: 显示各类文件数量和大小
- **自动刷新**: 支持手动刷新数据统计

### 2. 智能清理配置
- **存储上限设置**: 可设置数据存储上限（10-500MB）
- **清理策略选择**: 
  - 🕐 **删除最早的文件**: 按创建时间清理
  - 📉 **删除性能最差的模型**: 按模型性能清理
- **文件类型选择**: 
  - 🤖 清理AI模型文件（*.pkl）
  - 📈 清理股票数据文件（*.csv）

### 3. 多种清理模式
- **智能清理**: 自动清理超过上限的数据
- **手动选择**: 手动选择要删除的文件
- **详细分析**: 生成详细的存储分析报告

## 🚀 使用指南

### 第一步：启动GUI
```bash
python AI量化交易系统GUI.py
```

### 第二步：进入数据管理标签页
1. 点击左侧的 **"💾 数据管理"** 标签页
2. 查看当前数据存储状态
3. 配置清理参数

### 第三步：配置清理参数
1. **设置存储上限**: 拖动滑块或输入数值（建议100-200MB）
2. **选择清理策略**: 根据需求选择清理方式
3. **选择文件类型**: 勾选要清理的文件类型

### 第四步：执行清理
- **快速清理**: 点击"🧹 智能清理"按钮
- **详细分析**: 点击"🔍 分析数据占用"查看详情
- **手动操作**: 点击"⚠️ 手动选择删除"精确控制

## 🔧 技术实现

### 文件扫描机制
- **AI模型文件**: 扫描所有 `.pkl` 文件
- **股票数据**: 扫描 `金融数据` 目录下的 `.csv` 文件  
- **分析报告**: 扫描 `分析数据` 目录下的所有文件

### 智能清理算法
```python
# 1. 计算当前总占用
current_size = sum(所有文件大小)

# 2. 判断是否需要清理
if current_size > limit_size:
    # 3. 根据策略排序文件
    if strategy == "oldest":
        files.sort(key=创建时间)  # 最旧的文件在前
    elif strategy == "worst":
        files.sort(key=模型性能)  # 性能最差的在前
    
    # 4. 按顺序清理直到满足上限
    for file in sorted_files:
        if current_size <= limit_size:
            break
        delete(file)
        current_size -= file.size
```

## 📈 最佳实践建议

### 存储配置建议
| 使用场景 | 推荐上限 | 清理策略 |
|---------|---------|---------|
| 日常使用 | 100-200MB | 删除最早的文件 |
| 模型训练 | 300-500MB | 删除性能最差的模型 |
| 数据存档 | 50-100MB | 手动选择删除 |

### 文件保留建议
- **重要模型**: 手动备份重要AI模型文件
- **历史数据**: 定期导出重要股票数据
- **分析报告**: 重要报告建议导出为PDF

## 🛠️ 故障排除

### 常见问题

**Q: 进度条不显示或显示异常？**
A: 点击"🔄 刷新统计"按钮重新计算

**Q: 清理后文件仍存在？**
A: 可能是文件被占用，请关闭其他程序后重试

**Q: 存储计算不准确？**
A: 系统只计算指定类型的文件，其他文件不计入

**Q: 手动选择删除无法选择文件？**
A: 确保文件没有被其他程序打开

### 性能优化
- 建议定期清理，避免一次性清理大量文件
- 大文件清理时请耐心等待
- 清理过程中不要关闭程序

## 📞 技术支持

如遇到问题，请检查：
1. 文件权限是否正常
2. 磁盘空间是否充足
3. 程序是否以管理员权限运行
4. 日志输出是否有错误信息
