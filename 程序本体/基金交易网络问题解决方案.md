# 基金交易功能 - 网络问题解决方案

## 问题说明

在使用基金交易功能时,可能会遇到以下网络相关错误:

```
✗ 查询失败: HTTPSConnectionPool(host='88.push2.eastmoney.com', port=443): Read timed out. (read timeout=15)
```

这是由于akshare库访问东方财富数据接口时出现网络超时造成的。

## 已实施的优化

### 1. **自动重试机制**

已添加`get_fund_data_with_retry()`方法,包含:
- 最多重试2次
- 每次重试间隔2秒
- 失败后自动降级到模拟数据

### 2. **错误处理增强**

- 禁用SSL警告(urllib3)
- 详细的日志输出
- 清晰的错误提示
- 优雅降级处理

### 3. **模拟数据备份**

当网络请求失败时,系统会自动使用模拟数据:
- 随机生成基金净值(1.0-3.0元之间)
- 生成基金名称和类型
- 标记为"模拟数据"以便区分

## 解决方案

### 方案1: 等待重试(推荐)

系统已内置重试机制,通常会自动恢复:
- 首次查询可能超时
- 等待几秒后系统会自动重试
- 重试2次后仍未成功则使用模拟数据

### 方案2: 检查网络连接

确保网络连接正常:
```
1. 检查网络是否连接
2. 尝试访问东方财富网站: http://fund.eastmoney.com/
3. 检查是否有代理或防火墙阻止访问
```

### 方案3: 增加网络超时时间(高级)

如果网络较慢,可以修改代码中的超时设置:

在`get_fund_data_with_retry()`方法中:
```python
def get_fund_data_with_retry(self, fund_code, max_retries=2, timeout=10):
    # 将timeout从10增加到30
    timeout=30
```

### 方案4: 使用代理(高级)

如果需要通过代理访问网络,可以配置:

```python
import os
os.environ['HTTP_PROXY'] = 'http://your-proxy:port'
os.environ['HTTPS_PROXY'] = 'http://your-proxy:port'
```

2. 自动切换到模拟数据模式

## 基金数据来源说明

akshare库使用的基金数据源:

### ETF基金(交易所交易基金)
- 接口: `ak.fund_etf_spot_em()`
- 数据源: 东方财富
- 特点: 实时数据,更新频率高

### 开放式基金
- 接口: `ak.fund_em_open_fund_info()`
- 数据源: 东方财富
- 特点: 每日更新净值

### 基金搜索
- 接口: `ak.fund_em_open_fund_search()`
- 数据源: 东方财富
- 特点: 搜索基金基本信息

## 常见问题

### Q1: 为什么会网络超时?

A: 可能原因:
- 网络连接不稳定
- 东方财富服务器响应慢
- 防火墙或代理阻止
- 网络运营商限制

### Q2: 模拟数据会影响功能吗?

A: 不会影响:
- 买入、卖出功能正常
- 持仓管理正常
- 盈亏计算正常
- 只是净值数据不是实时的

### Q3: 如何获得真实数据?

A: 需要:
- 稳定的网络连接
- 正常访问东方财富网站
- 安装akshare库: `pip install akshare`

### Q4: 重试次数可以调整吗?

A: 可以,修改以下代码:
```python
fund_data = self.get_fund_data_with_retry(
    fund_code, 
    max_retries=3,  # 增加重试次数
    timeout=10       # 增加超时时间
)
```

### 使用模拟数据测试流程

1. **查询基金**:

   - 持仓列表显示买入的基金

3. **刷新净值**:
   - 点击"刷新净值"
   - 系统生成新的模拟净值
   - 盈亏自动重新计算

4. **卖出基金**:
   - 输入基金代码和份额
   - 点击"卖出"
   - 系统根据模拟净值计算金额

## 实际使用注意事项

1. **网络不稳定时**:
   - 系统会自动使用模拟数据
   - 功能正常,但数据非实时
   - 适合测试和演示

2. **网络稳定后**:
   - 删除模拟数据持仓
   - 重新查询真实基金
   - 开始使用真实数据交易

3. **混合使用**:
   - 可以同时持有模拟和真实基金
   - 模拟基金标记为"模拟基金"类型
   - 便于区分
