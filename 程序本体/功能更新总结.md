## 三、AI交易决策逻辑

### 3.1 决策因素
AI交易建议基于以下因素综合判断:

1. **AI预测信号**
   - 看涨 (prediction = 1)
   - 看跌 (prediction = -1)
   - 中性 (prediction = 0)

2. **持仓状态**
   - 无持仓
   - 有持仓(含持仓数量、成本价)

3. **持仓盈亏**
   - 亏损百分比
   - 盈利百分比

### 3.2 决策矩阵

| 持仓状态 | AI预测 | 盈亏情况 | 建议 |
|---------|--------|----------|------|
| 无持仓 | 看涨 | - | 买入建仓 |
| 无持仓 | 看跌/中性 | - | 观望 |
| 有持仓 | 看涨 | 亏损>5% | 加仓摊低成本 |
| 有持仓 | 看涨 | 盈利<5% | 继续持有 |
| 有持仓 | 看涨 | 盈利>5% | 分批止盈 |
| 有持仓 | 看跌 | 盈利>5% | 及时止盈 |
| 有持仓 | 看跌 | 小幅盈利 | 减仓或清仓 |
| 有持仓 | 看跌 | 亏损 | 止损 |
| 有持仓 | 中性 | 盈利>10% | 止盈 |
| 有持仓 | 中性 | 亏损>10% | 止损 |
| 有持仓 | 中性 | 其他 | 继续持有 |

## 六、使用流程示例

### 示例1: 新手建仓流程

1. **打开持仓管理标签页**
   - 查看: 可用资金 100,000.00 元

2. **买入建仓**
   - 股票代码: `000001`
   - 数量: `100`手
   - 价格: `10.50`元
   - 点击买入

3. **查看持仓**
   - 持仓表格显示新买入的持仓
   - 盈亏暂为0(刚买入)

4. **开始实时监控**
   - 输入股票代码: `000001`
   - 开始监控

5. **查看AI建议**
   - 实时监控面板显示AI交易建议
   - 根据建议决定是否调整持仓

### 示例2: 策略验证流程

1. **先回测策略**
   - 选择股票: `000001`
   - 选择AI模型: 随机森林
   - 开始回测

2. **对比持仓表现**
   - 回测结果显示: 收益率 +15.20%
   - 系统显示: 持仓收益率 +6.67%
   - AI建议: 策略表现优秀,建议按策略操作

3. **决定实际操作**
   - 如回测表现好且持仓亏损,考虑加仓
   - 如回测表现差,考虑减仓或止损

### 示例3: 风险管理流程

1. **监控持仓盈亏**
   - 每日查看持仓管理标签页
   - 关注总盈亏百分比

2. **触发止损**
   - 某只股票亏损超过10%
   - AI建议: 止损
   - 执行卖出操作

3. **止盈操作**
   - 某只股票盈利超过10%
   - AI建议: 分批止盈
   - 分批卖出锁定收益
