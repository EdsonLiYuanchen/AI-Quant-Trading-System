# 持仓显示问题解决方案

## 问题描述
在持仓管理中输入了持仓信息，但实时监控显示的资产还是100万（初始资金），而不是实际的总资产。

## 问题原因

### 1. 持仓价格未更新
当您在GUI中手动输入持仓信息买入时：
- 持仓的`current_price`（当前价格）会被设置为买入价格
- 但这可能不是市场实际价格
- 如果这个价格设置得很大（比如10000元），市值就会很高

### 2. 持仓计算逻辑
总资产计算公式：
```
总资产 = 可用现金 + ∑(持仓数量 × 当前价格 × 100)
```

如果您输入的买入价格不正确，或者持仓的当前价格没有更新，就会导致显示的总资产不准确。

---

## 解决方案

### 方案1：使用"更新价格"按钮（推荐）

1. 打开GUI程序
2. 切换到"💼 持仓管理"标签页
3. 点击 **"📊 更新价格"** 按钮
4. 系统会自动：
   - 从数据源获取所有持仓股票的最新价格
   - 更新持仓的当前价格
   - 重新计算总资产
   - 刷新显示

**优点**：
- 自动获取最新价格
- 确保数据准确
- 支持批量更新所有持仓

### 方案2：实时监控时自动更新

实时监控功能已优化，现在会：
- 每次获取股票数据时
- 自动更新该股票在持仓中的当前价格
- 自动保存持仓数据

**步骤**：
1. 切换到"📡 实时监控"标签页
2. 输入您持有的股票代码
3. 点击"🚀 开始监控"
4. 系统会自动更新价格

**注意**：只在监控的股票范围内会自动更新

### 方案3：手动输入正确的价格

如果您想手动设置价格：

1. 在持仓管理标签页
2. 查看您的持仓
3. 检查"现价"列是否合理
4. 如不合理，可以：
   - 先卖出该持仓
   - 重新买入时输入正确的价格

## 验证步骤

### 1. 检查持仓明细
在"💼 持仓管理"标签页，查看：
- **数量(手)**：是否正确
- **成本价**：是否为您买入的实际价格
- **现价**：是否为当前市场价格
- **市值**：数量 × 现价 × 100
- **盈亏**：（现价 - 成本价）× 数量 × 100

**示例**：
```
股票代码: 000001
数量(手): 100
成本价: 10.50
现价: 11.20
市值: 112,000.00 (100 × 11.20 × 100)
盈亏: +7,000.00 ((11.20 - 10.50) × 100 × 100)
盈亏%: +6.67%
```

### 2. 检查资金信息
查看标签页顶部的资金信息：
- **可用资金**：剩余的现金
- **总资产**：可用资金 + 所有持仓市值
- **总盈亏**：总资产 - 初始资金(100,000)

**预期**：
```
可用资金: 8,950.00 元
总资产: 120,950.00 元 (8,950 + 112,000)
总盈亏: +20,950.00 元 (+20.95%)
```

### 3. 检查数据文件
打开程序目录，查看：
- `portfolio.pkl` - 二进制数据
- `portfolio.json` - JSON格式（可用记事本打开）

检查JSON中的价格数据是否正确：
```json
{

      "current_price": 11.2,  // 检查这个价格

```

## 常见问题

### Q1: 为什么显示100万？
**A**: 可能的原因：
1. 买入时输入的价格过大（如10000元而不是10元）
2. 持仓数量输入错误（手而不是股）
3. 持仓价格未更新

**解决**：
- 检查持仓明细中的"现价"是否合理
- 点击"更新价格"按钮获取最新价格
- 如仍有问题，清空持仓重新输入

### Q2: 更新价格后还是不对？
**A**: 检查：
1. 数据源是否可用（需要akshare库）
2. 股票代码是否正确
3. 网络连接是否正常
4. 查看右侧日志的错误信息

### Q3: 盈亏计算不正确？
**A**: 盈亏计算公式：
```
盈亏 = (现价 - 成本价) × 数量(手) × 100
盈亏% = 盈亏 / 总成本 × 100%
```

其中：
- 成本价 = 总成本 / (数量 × 100)
- 如果多次买入同一只股票，成本价会加权平均

### Q4: 可用资金和总资产的关系？
**A**:
```
可用资金 + 持仓市值 = 总资产
总资产 - 初始资金(100,000) = 总盈亏
```
