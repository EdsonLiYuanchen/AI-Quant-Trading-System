## 测试步骤

### 测试1: 查询基金(模拟数据)

```
1. 在"基金查询"区域输入: 159915
2. 点击"🔍 查询基金"按钮
3. 查看右侧日志和基金信息显示
```

**预期结果**:
- 日志显示查询过程
- 基金信息区域显示基金详情
- 如果网络超时,会自动使用模拟数据

### 测试2: 买入基金

```
1. 在"基金交易"区域输入:
   - 基金代码: 159915

2. 点击"💰 买入"按钮
3. 查看"基金持仓"表格
```

**预期结果**:

- 基金持仓表格出现新记录
- 显示份额、净值、市值等信息

### 测试3: 再次查询相同基金

```
1. 在"基金查询"区域输入: 159915
2. 点击"🔍 查询基金"按钮
```

**预期结果**:


**预期结果**:

- 盈亏金额和百分比自动重新计算

### 测试5: 卖出基金

```
1. 查看"基金持仓"表格,找到持有的基金
2. 在"基金交易"区域输入:
   - 基金代码: 159915
   - 份额: (从表格中查看,如: 500)
3. 点击"💸 卖出"按钮
```

**预期结果**:
- 日志显示卖出成功
- 持仓表格中的份额减少

### 测试6: 查看交易记录

```
1. 点击"📜 交易记录"按钮
```

**预期结果**:

- 包括日期、操作类型、基金信息、净值、份额、金额、盈亏

### 测试7: 测试多只基金


**预期结果**:
- 持仓表格显示多只基金
- 每只基金的盈亏分别计算
- 刷新后所有净值都更新

### 测试8: 清空持仓

```
1. 点击"🗑️ 清空持仓"按钮
2. 在确认对话框中点击"是"
```

## 网络问题处理

### 如果出现超时错误

**方法1**: 等待自动重试
- 系统会自动重试2次
- 每次间隔2秒
- 失败后使用模拟数据

**方法2**: 使用模拟数据测试
- 模拟数据功能完全正常
- 可以完整测试所有功能
- 数据会标记"(模拟数据)"

**方法3**: 检查网络
- 尝试访问: http://fund.eastmoney.com/
- 确认网络连接正常
- 检查是否有防火墙限制

## 故障排查

### 问题1: 按键没反应

**解决**:
- 确保输入了有效的基金代码
- 检查金额或份额是否为正数
- 查看右侧日志区域是否有错误信息

### 问题2: 持仓不显示

**解决**:
- 点击"📊 更新持仓"按钮
- 检查是否真的有持仓
- 查看`fund_portfolio.json`文件

### 问题3: 盈亏计算错误

**解决**:
- 点击"🔄 刷新净值"更新最新净值
- 检查持仓的净值是否正确
- 查看交易历史记录

### 问题4: 程序卡住

**解决**:
- 所有操作都在后台线程执行
- 查看日志区域是否有输出
- 等待几秒,网络请求可能需要时间
